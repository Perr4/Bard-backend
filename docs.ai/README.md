# docs.ai — file di lavoro dell'agente

Cartella degli artefatti prodotti durante il lavoro: bug aperti, note di verifica,
report di analisi, bozze. Non è la documentazione ufficiale del progetto (quella è
in `../docs/`).

## Contenuto

| File | Contenuto |
|---|---|
| `BUG-APERTI.md` | Bug emersi dalle verifiche, con sintomo/causa/correzione. Da rivedere. |

## Convenzione

- I file qui sono **di lavoro**: possono essere incompleti, soggetti a verifica o
  destinati a finire nella documentazione ufficiale.
- Quando un bug è risolto e verificato, si sposta la voce in `../docs/BUG-APERTI.md`
  o si aggiorna la documentazione di riferimento.
- I report di verifica (output di test, log) si tengono qui finché non servono come
  prova, poi si riassumono nei documenti ufficiali.
